API Connections

Anthropic API key

Used for both interactive chat and the autonomous cycle. Stored encrypted on disk via the OS keychain (Windows DPAPI). Never written in plain text.

Or set ANTHROPIC_API_KEY as an environment variable before launching Mio — the env var wins over the stored key.

Gemini API key (TTS voice)

Optional. Used to synthesize Mio's spoken voice (startup greeting and the post-reply line read in the caption) in the "Leda" voice via gemini-3.1-flash-tts-preview. Each line of text is generated once and cached on disk; subsequent plays are offline.

Or set GEMINI_API_KEY (or GOOGLE_API_KEY) as an environment variable. Voice playback is skipped silently when no key is configured.

ComfyUI (image generation)

Lets Mio draw with a local ComfyUI server. Run ComfyUI with --enable-cors-header *. The default workflow uses GrokImageNode — a Comfy Cloud Partner Node that bills against your Comfy Cloud credit balance, so we also need your Comfy Cloud API key from platform.comfy.org. Both are stored encrypted on disk via the OS keychain (Windows DPAPI); neither is ever written in plain text. Mio decides on her own when to draw — she is never forced.

The key is sent to your local ComfyUI server in extra_data.api_key_comfy_org on every workflow submission so Partner Nodes (Grok, Flux Pro, Ideogram, …) can authorize against your Comfy Cloud subscription. Or set COMFY_CLOUD_API_KEY as an environment variable — the env var wins over the stored key.

Test connection probes both the local server (/system_stats) and the Comfy Cloud key (/api/user) — both must pass for Partner-Node workflows to succeed. Hourly burst cap (10/hour) and per-cycle cap (1/cycle, autonomous loop only) are fixed. Generated PNGs land in <app-data>/generated/ — no other path is accepted.

Conversation sessions

Mio remembers everything you say to her per session. Pick the conversation she should pick up from, start a fresh one, or clear history when you want a clean slate.

Starting a new session plays Mio's greeting line (audio if a Gemini key is configured, text-only otherwise).

Greeting line

The line Mio speaks on every fresh session. Defaults to the quoted line in persona.md under On startup. Editing here overrides the file without modifying it.

Agent tools

When enabled, Mio can use tools to act on your PC — read files, search the web, drive a browser, write files, and run commands. Reads, web search, and browsing are free; anything that changes your machine asks for your approval first.

Chat

Talking to Mio from anywhere on the desktop.

Ctrl+Enter global
Summon the typing bar near Mio's feet. Press again to dismiss it.
Enter in input
Send the message. The current screen is attached automatically.
Esc in input
Hide the typing bar and return focus to the desktop.
Ctrl+V in input
Paste an image from the clipboard to attach to the next message (PNG, JPEG, WebP, or GIF). Persisted in chat history.

Avatar window

Repositioning Mio on the desktop.

Alt + drag on avatar
Reposition Mio anywhere on the desktop.

Touching Mio directly (caress, poke, tickle, and friends) lives on its own page — see Gestures.

Global hotkeys (like Ctrl+Enter) only register once on launch. If another app already owns the combo, the tray icon is your fallback for opening chat.

Touch input

Mio has a body-wide proprioceptive map. Move the mouse over her, use one of the gestures below, and she reacts in character. Each gesture has a per-region cooldown so a single touch doesn't trigger over and over. Rapid bursts get coalesced into one reply so she doesn't stutter through a flurry of pokes.

Alt + drag is reserved for repositioning the avatar window — gestures never fire while Alt is held.

Gestures

Hover ~1.5 s on a region
Caress — sustained gentle touch. Affectionate on face / hair, ticklish on sides / feet, bashful on ears / lips / collarbone.
Click on a region
Poke — a quick prod. Plays as "hey, you" at the spot you tapped.
Click + Click < 0.4 s apart
Pat — a double-tap on the same region. Reads softer than a poke.
Wiggle inside a region
Tickle — rapid side-to-side mouse motion in one spot. Best results on sides, palms, feet, neck.
Hold + drag along a limb
Stroke — slide along the length of an arm, leg, or limb segment. The drag has to roughly follow the bone direction.
Hold still ~0.35 s
Grab — press and hold without moving. Reads as a deliberate clasp on the spot.
Hold + drag away on hair / skirt
Tug — pull a soft part outward. Only fires on hair, skirt, ribbon, and similar spring-bone chains.
Right click on a region
Pinch — a sharp two-finger pinch. Sharper than a poke; tends to draw a startled reaction.

What she can feel

Her body map covers head and face (forehead, cheeks, ears, lips, chin, temples, back of head, nape of neck), neck, torso (collarbone, upper chest, sides, stomach, upper and lower back), arms (shoulders, upper arms, elbows, forearms, palms, and each individual finger), and legs (thighs, knees, shins, calves, ankles, feet, toes). Hair, skirt, and ribbon are picked up from her spring bones automatically — the exact zones depend on what's rigged on the loaded VRM.
